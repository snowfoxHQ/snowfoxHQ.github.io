    Hestia 是一个开放式 AI 基础设施项目。它不把智能看成单一语言模型，而看成长期记忆、知识组织、Agent、自主推理与执行等多种核心能力协同工作的统一认知操作系统。

    目前生态覆盖认知操作系统（Hestia OS）、长期记忆运行时（HMR）、语义记忆检索（VecRecall）、知识组织与演化（HKC）以及企业级 Agent 运行基础设施。所有项目以 MIT / Apache 2.0 为主，开放、可复用、离线优先。

    这套主页本身也是一个作品：零依赖、单文件、可直接部署到 GitHub Pages。

    Hestia

    为下一代 AI 构建可复用的认知基础设施。让智能体真正拥有记住、推理、组织、学习与进化的能力。
